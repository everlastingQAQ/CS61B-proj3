# DESIGN

## 游戏玩法设计

### 通关条件

5 个物品获得任意 3 个遗物 -> 出口激活 -> 活着走到出口 -> WIN

### 核心玩法

5 个物品获得任意 3 个遗物, 有buff也有debuff, 怪物只躲避不击败
